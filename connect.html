Connect to QuickBooks

How an Authorized User connects Sud Scrub Analytics to a QuickBooks Online company file.

Sud Scrub Analytics is an internal-use application. Connection is initiated by the Company's authorized consultant from their local workstation using the following steps:

  1. The consultant runs the local OAuth launcher included with the Sud Scrub Analytics toolkit. The launcher opens a browser window to Intuit's authorization endpoint.
  2. The Authorized User (an admin on the target QuickBooks Online company file) signs in to their Intuit account.
  3. Intuit presents a consent screen listing the scope requested (com.intuit.quickbooks.accounting — read-only accounting data).
  4. The Authorized User reviews the scope and the End User License Agreement and Privacy Policy, then approves the connection.
  5. Intuit redirects to the consultant's local workstation, which exchanges the authorization code for access and refresh tokens. Tokens are stored with restricted file permissions on the consultant's workstation.
  6. The connection is confirmed and the Application can then pull read-only reports on request.

To revoke an existing connection, see Disconnect.
